# ADR-001: API Data and Offline SQLite Cache

**Date:** 2026-11-05
**Author:** Azra Çetinkaya
**Milestone:** Lab 4 / P1 / P2 / P3 / P4 / P5 / P6
**Tool and model used:** ChatGPT - GPT-6

## Context
The goal was to build a campus feed application that gets posts from a web API and works without an internet connection. The application needed to save posts locally and display them when the network was unavailable.

## Prompt
Help me implement the Campus Feed lab step by step. Implement JSON conversion, network fetching, offline fallback, SQLite caching, and tests. Explain the code in simple language.

## Result
The AI helped implement the Post model, API requests, repository logic, ViewModel, screen, and SQLite cache. The SQLite cache saves posts inside a transaction and loads them ordered by ID. Two additional tests were added to check invalid JSON data and HTTP 404 responses.

## Rejected suggestion(s) — at least one
The AI incorrectly identified the curly braces ({}) as the source of the coding error and suggested an incorrect solution. I rejected this suggestion, examined the code myself, found the actual problem, and corrected it manually.

## Verification
All 14 lab tests passed. The two additional tests in own_test.dart also passed. The application was tested on an Android emulator. Posts were loaded while online, then the internet was disabled and the application was restarted. The saved posts were displayed with the "Offline - showing saved posts" message.

## What I learned
I learned how to work with a web API and save data in an SQLite database. I also learned how to test offline behavior and verify AI-generated code.
